### Section Details

**What It Does** (3–4 sentences): Docifer ingests PDF documents, extracts text, table, and visual evidence into canonical artifacts, indexes them into a vector store, and serves grounded answers with citation verification. Designed for high-precision retrieval on financial filings.

**Key Metrics** (callout block):
```
recall=0.723  |  citation_precision=0.941  |  false_abstention=0.019
68-question golden dataset · 8 Tesla 10-Q/10-K filings · Phase 14 config
```

**Architecture**: Mermaid diagram inline — renders on GitHub. Also links to `docs/architecture.svg` for full standalone asset.

**Features** (bullet list by capability):
- PDF ingestion → text / table / visual artifact extraction via Docling
- Hybrid retrieval (dense + BM25) with optional cross-encoder reranking
- Multimodal evidence assembly (text chunks + table cells + visual embeddings)
- Citation verification via LLM grounding check
- Abstention + retry for low-confidence answers
- Document registry APIs with modality readiness and audit status
- React workbench UI — document rail, query composer, answer panel, evidence/debug panel

**Quick Start** (prereqs: Python 3.11+, Node 18+, uv, OpenAI API key in `.env`; 5 commands: clone → `uv sync --project backend` → start backend → `npm install` in `frontend/` → `npm run dev`).

## 2. Architecture Diagram (`docs/architecture.svg`)

Generated by `scripts/generate_architecture_svg.py` — a one-off script that writes a static SVG string to `docs/architecture.svg`. No external diagram library required; pure SVG.

### Layout

Left-to-right data flow across three horizontal layers:

**Ingestion layer** (blue):
```
PDF Files → Docling Parser → Canonical Artifacts
                              (text chunks / table cells / visual images)
```

**Index layer** (teal):
```
Canonical Artifacts → Indexer → Qdrant (text vectors)
                              → Qdrant (table vectors)
                              → Qdrant (visual embeddings)
                              → PostgreSQL (document registry)
```

**Query layer** (green + purple):
```
Query → Hybrid Retriever (dense + BM25)
      → Evidence Assembler (text + table + visual)
      → Citation Verifier (LLM grounding check)
      → Answer + Citations
      ↑
React Workbench UI
```

### SVG Spec

- Canvas: 900×520 px
- Color palette: ingestion=#2563eb, index=#0d9488, query=#16a34a, ui=#7c3aed
- Rounded rect nodes (rx=6), 14px sans-serif labels
- Arrows: `stroke=#475569`, `marker-end` arrowhead
- Committed to `docs/architecture.svg`, linked from README `## Architecture` section

## 3. Demo Script (`scripts/demo.py`)

Standalone script. No dependencies beyond the standard library + `urllib` (no third-party packages needed).

### Behaviour

1. `GET /ready` — print backend status and check count
2. `GET /documents?limit=200` — print indexed document list (id, filename, modality status)
3. `POST /query` — run one hardcoded question against the first available document; print answer, top 3 citations, latency ms
4. Print summary line: `✓ Docifer demo complete`

### Configuration

- Default API base: `http://127.0.0.1:8000`
- Override: `DOCIFER_API_URL` environment variable
- Exits with code 1 and descriptive error if backend not reachable

### Hardcoded demo question

```
"What was Tesla's total revenue for the most recent reported quarter?"
```

Generic enough to work across any of the Tesla filings in the corpus.

### Usage

```powershell
uv run --project backend python scripts/demo.py
# or with custom URL:
$env:DOCIFER_API_URL = "http://127.0.0.1:8000"
uv run --project backend python scripts/demo.py
```
